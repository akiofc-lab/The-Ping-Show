# Where each sound effect comes from

Recordings are public-domain (CC0) clips from Freesound, taken from the ESC-50 dataset
(https://github.com/karolpiczak/ESC-50), which lists the licence of every clip.
A few more public-domain (CC0) Freesound recordings come through the Sonic Pi sample set
(https://github.com/sonic-pi-net/sonic-pi, WAV copies from https://github.com/adafruit/Adafruit-Sound-Samples).
Instrument notes come from the FluidR3_GM soundfont by Frank Wen, as pre-rendered by
midi-js-soundfonts (https://github.com/gleitz/midi-js-soundfonts), Creative Commons
Attribution 3.0. The rest is computed.
