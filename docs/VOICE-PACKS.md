# Writing a voice pack

[← Back to the README](../README.md)

A pack is one JSON file:

```json
{
  "format": "ping-show-pack/1",
  "id": "my-pack",
  "name": { "en": "My pack", "fr": "Mon paquet" },
  "characters": [
    {
      "id": "butler",
      "name": { "en": "The weary butler", "fr": "Le majordome fatigué" },
      "role": { "en": "the weary butler", "fr": "le majordome fatigué" },
      "keywords": ["butler", "majordome"],
      "gender": "m",
      "voice": "V76",
      "pitch": 0.95, "pace": 0.9, "expressiveness": 0.4, "volume": 1, "tail": 0.2,
      "effects": [["bass", 3, 110], ["echo", 0.9, 0.7, [60], [0.1]]],
      "jingle": "clavecin",
      "background": [{ "sound": "bell", "at": 1.5, "freq": 880, "length": 1.2, "level": 0.5 }],
      "catchphrases": {
        "en": { "before": ["Very good.", "If I may,"], "after": ["Will that be all?"] },
        "fr": { "before": ["Fort bien.", "Si je puis me permettre,"], "after": ["Ce sera tout ?"] }
      },
      "icon": "<circle cx=\"24\" cy=\"24\" r=\"16\" fill=\"#8ed1fc\"/>"
    }
  ]
}
```

Only `format`, `name`, and for each character `name` and `voice` are
required.

- **voice**: `L0`–`L903` (American speakers) or `V0`–`V108` (British
  speakers). Messages in French use one French voice per gender.
- **pitch** 0.6–1.6, **pace** 0.5–1.6 (1 = natural), **expressiveness** 0–1.
  Beyond roughly 0.85–1.25 for pitch and 1.15 for pace, voices get hard to
  follow.
- **effects**, applied in order: `bass` (dB, Hz), `treble` (dB, Hz),
  `lowpass` (Hz), `highpass` (Hz), `peak` (Hz, dB, width), `echo` (dry
  level, output level, [delays in ms], [levels]), `tremolo` (Hz, depth),
  `vibrato` (Hz, depth), `flanger` (delay ms, depth ms, speed Hz, mix),
  `crackle` (drive, steps, mix), `robot` (window 256–2048, –, mix),
  `whisper` (mix), `growl` (Hz, depth, drive), `glitch` (seed, seconds
  between stutters), `compress` (threshold, ratio). Values are clamped to
  safe ranges.
- **jingle**: the name of one of the 51 jingles in `extension/indicatifs/`
  (without `.wav`), or your own short sound as a `data:audio/…;base64,…`
  address (3 seconds at most).
- **background**: up to 24 short sounds in an eight-second loop. Each has a
  `sound` (`bell`, `toll`, `pluck`, `drop`, `knock`, `thump`, `beep`,
  `glide`, `croak`, `scratch`), a time `at` (seconds), a `freq` (Hz), and
  optionally `length`, `level` (0–1), `decay`, `rise`, `to` (for `glide`).
- **catchphrases**: `before` and `after` lists, per language.
- **icon**: SVG drawing for a 48 × 48 box (the inside of the `<svg>` tag).
  It is shown as an image; scripts and links are refused.
- **keywords**: extra words people can use after `!voice`.

When a pack is added, the panel says what it skipped or corrected.

The three packs that ship with the extension are generated by
`tools/packs/build-packs.cjs`; you can also edit the JSON files by hand.
